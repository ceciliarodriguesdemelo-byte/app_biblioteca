# App Biblioteca - Flutter & Firebase

Aplicativo Mobile desenvolvido para o controle de livros em uma biblioteca, juntando autenticação e banco de dados (firebase).

## Funcionalidades
* **Autenticação**: Cadastro e Login de usuários via Firebase Auth.
* **CRUD de Livros**: Criação, leitura, edição e exclusão de registros de livros.
* **Banco de Dados**: Inserção de dados utilizando Cloud Firestore.
* **Interface Responsiva**: Desenvolvido com Flutter.

## Tecnologias Utilizadas
* [Flutter](https://flutter.dev/) - Framework UI
* [Firebase Authentication](https://firebase.google.com/products/auth) - Gestão de usuários
* [Cloud Firestore](https://firebase.google.com/products/firestore) - Banco de Dados NoSQL
